# sonar_ray_visibility：三维首交点能否修正框偏移

2026-11-13，运行前登记。目的：隔离自遮挡与注册误差，检验文献启发的首交点控制是否足以解释已有框的横向错位。

- 唯一改动：同一 OBJ、同一固定姿态和同一三维射线集合上，完整表面的全部交点改为每条射线最近的交点。双面三角形，不按法向或强度删点；不加入不存在的池底/支架网格。
- 对照：解析长方体；两层前后平面；前后平面具有不同仰角支持的例子。独立 Möller–Trumbore 射线求交验证光栅化交点。
- 实物资产：只取既有 RGB pilot 的 mortar103728 和 grenade123500 各三帧，均为当前 train；用旧 PCA 与既有 box_guided 固定姿态各一套，不拟合。读取相应 ARIS 元数据和图像；不读新旧 test 图像/逐帧标签，不评价模型。
- 指标：raw 方位左右边、最近/最远斜距边的差；512 与 1024 射线网格的收敛差；完整框/可见框包含关系。先按二维方向 x/z、y/z 分射线，再合并仰角，绝不按方位单独取最近。
- 判定：若同射线的左右边和最近边恒定、仅远边改变，则首交点不能修复横向位移；仅可解释特定远距边变化。此为几何支持结论，不认证反射强度、真实姿态或多径。
- 通过条件：解析交点误差 <1e-9 m，随机射线独立求交误差 <1e-8 m；真实资产两分辨率各边差 <=0.5 raw 像素才用于量化，超限明确标不收敛，不扩参数追框。
- 停止：实现控制失败时不跑实物；无可靠人工物理对应时不启动 AnP/PnP，不产 GT。保存失败与未收敛，原研究、当前数据集/划分/训练不变。

同时目视核对原 pilot RGB 与纹理视图库，记录是否有足够独立、可跨视角认定的物理对应；轮廓切点/重复结构不当已知点。
