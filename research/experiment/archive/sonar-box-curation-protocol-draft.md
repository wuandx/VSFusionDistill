# sonar_box_curation_v1_draft：几何框、QA 与异常处理草案

2026-11-11。**草案，尚未执行或冻结；不改变已有 18 帧标签状态、划分或测评协议。** 原研究只读，原项目 test 关闭，不训练。本文件依据 CMHD §3.1 的投影与人工 QA 路线制定我方可执行细则；下述阈值、角色与处理方法均为我方建议，不能写成作者实现。

## 目的、唯一变化与对照

- 目的：得到定义明确、来源可追溯的 sonar 轴对齐框；定位失败应由坐标/注册误差、真实不可见、截断或声学外观解释，不用“渲染 mask 必须贴住每个亮像素”代替框 QA。
- 唯一变化：先修订框定义与 QA 判据，并重新登记观察；本阶段不借此改变 beam 符号、mesh 尺度/位姿、外参、同步或 FOV。若随后拟合固定注册，另立具备参数/预算的 run。
- 对照：既有初版与反号候选、无叠框原图、独立记录的可见目标证据。旧 `blob` / `projected` 不能充当独立参考 GT。
- 保留：全部失败、无信号、分歧、候选框及原判据。不能把新判据产生的状态变化静默回写为原试验成功。

## 框的标注对象和坐标

目标是 UXO 本体，包含实际属于该弹体的尾翼/端部，不包含支架、吊具、背景散射、声学阴影或多径。几何框表示物理 mesh 经确定坐标变换、投影和图像边界处理后的外包络；它不是亮像素 mask，不能要求框内全部明亮，也不要求高亮 ridge 恰好通过几何中心线。

每条候选同时保存：未裁切几何包络、裁切后的图像框、range/beam 截断标记、elevation 分布和使用的声束模型。全物体范围与声束内候选范围分别存储。当前 ±7°/±7.5° 是既有假设，不能把声束宽度直接当绝对的可见/不可见切换；未解决的垂直声束敏感性须进入框的不确定性记录。

先固定唯一训练图片类型及其生成版本，再输出该图片的框。raw range×beam、官方 polar2、本地 fan 的像素坐标不可互用；同一个三维候选应通过各自已验证的成像函数投影，不能把 raw 框四个角简单变换后当作非线性扇形投影的精确包络。所有数值诊断优先同时报米、度和 raw bin/beam，另报所选训练图坐标。

建议存 `bbox_geometry_unclipped`、`bbox_geometry_clipped`、`bbox_curated` 三列。第三列在没有修订时等于第二列；发生人工修订时保存前后坐标、原因、操作者类型及版本。用可见亮斑紧框替代物理外包络属于标注语义变化，须另列版本，不能仍称未经修改的几何框。

## 逐帧操作顺序

1. **隐藏所有候选框与历史标签**，先看全高 raw 原图及固定显示参数的对应扇形图。记录 `target_visible=yes/no/uncertain`、可信目标回波段、能确认的端点/边界区间、支架/阴影候选和不确定理由。调整显示只可用于观察，必须保存方式；不能逐图选择最能支持候选的增强版本作为唯一证据。
2. 对不能独立判断的边界标 unknown，不能用待检几何框反向补成“人工真值”。paired RGB 可帮助确认物体身份与本体/支架关系；未经验证的跨模态投影不得用作 sonar 边界真值。
3. 显示几何候选，分别核对目标身份、range 位置、beam 位置、已确认的本体范围、截断和跨帧运动关系。允许几何范围含暗区、散斑间隙及无高亮的物体表面。
4. 记录结论：`geometry_retained`（几何框保留）、`manual_revised`（人工修订）、`unresolved`（尚不确定）、`excluded`（按明确规则不进入本版）。这些是标签整理状态，不代表已经取得专家真值或完成训练准入。
5. 第二位复核者先看原图再看候选，独立填写相同字段；保留分歧。两位 assistant 的一致不等于两位专家，记录 `reviewer_type=assistant`。不追加“必须每帧专家重画”的隐含硬前置；如仅有 assistant 复核，就如实报告标签的验证程度。

## 异常处理

| 情况 | 处理规则 |
|---|---|
| 框内暗区/散斑孔洞，目标身份和范围无矛盾 | 不因暗像素比例高而否决；记录为声学外观，检查几何和可靠端部证据 |
| 高亮 ridge 偏离几何中心线但仍落在物体表面投影支持范围 | 不自动调位姿；高光不等于中心线 |
| 确认属于本体的连续回波明显超出几何范围 | 标记矛盾；先排查坐标、同步、固定注册与声束影响，不用外扩大框掩盖系统偏差 |
| 物体在 range/beam 图像边界截断 | 保存未裁切框并 clip 到图像；可确认本体部分且坐标链成立时允许保留，标 truncated；不能因为截断就删困难样本 |
| 只因未认证的 elevation 硬门限得到空框 | 保留不确定，不能认证目标不存在；报告声束假设敏感性 |
| 几何预计物体在范围内，但原图无可归属回波 | `unresolved`，不自动赋可见目标正框，也不当负样本；可另存“物理在场”元数据，不能混入可见目标任务 |
| 支架/阴影与本体不可分 | 记录 unknown；不能沿所有亮点外扩；人工可确定本体边界时才修订，否则保留为未解决 |
| 多个亮团但只有一个实体 UXO | 以实体为单位一个框；只有能归属本体的部分才影响人工边界；不把每个亮团当一物体 |
| 高可信几何和视觉证据互相矛盾 | 暂不准入该框，保留证据；不能选择更接近“好看叠图”的解释 |
| 需要人工移动框才能保留 | 明确记 `manual_revised`；人工框不再作为拟合同一注册后的独立验收证据 |

当前 `173329_0456`、`101131_0909` 仍为无可靠目标回波的历史 uncertain，不因本草案改成负样本。`120912_0802` 的复核分歧必须保留。其余 partial 需按上述框判据重新检查；不能把原 partial 统一升级，也不能因 mesh mask 与高光不同统一否决。

若两录音之间物体被移动，只有来自独立记录的每录音固定 target 初始位姿可用于检查。不能从第二轨迹回波重新拟合位置，再宣称跨轨迹泛化通过。没有同位证据时，跨轨迹失败只能说明“共享 target 位姿假设未通过”，不能独断 mesh 注册失败。

## 定量记录及判定

以下必须逐帧、逐轨迹、逐类报告，不能只给 pooled 均值。18 帧仅是开发试点，小样本不能证明全数据标注质量。

1. **独立观测误差**：对可信本体点/端部区间，报告它到预测表面投影支持集的单向最短残差及区间违反量；分别用 m/degree 与 bin/beam。支持集内的暗区不计为惩罚。距离和角度量纲分别归一化，不能原样混合做欧氏距离。
2. **人工边界不确定区间**：若能从原图独立判断某一侧，保存该侧允许坐标区间 `[l,u]`；预测边界在区间内误差为 0，超出取到最近端距离。unknown 不赋假数值。由操作者先记录区间，固定增加最多 1 个 beam / 2 个 range bin 作为采样容差是本草案默认值；它是我方选择，并非声学精度认证，不能事后扩宽以收纳失败。
3. **框比较**：只有人工参考和几何框具有同一“物理本体范围”语义且边界有足够证据时，才报 box IoU、中心偏差/框对角线、四边偏差、面积比。若人工框仅覆盖亮斑，则该 IoU 只是语义差异诊断，不作物理注册验收线。当前没有这类独立数值参考，不能补报已通过的 IoU。
4. **参数与框稳定性**：保存全部可接受固定注册候选的参数范围和逐帧框包络；报告候选两两 box IoU 最小值、中心跨度和四边跨度。可建议以最小 IoU≥0.90 且各边跨度不大于预登记边界容差标“框稳定”，仅说明当前候选集下框近似一致，不证明注册唯一或真实。
5. **QA 覆盖**：每类分别计可靠、unknown、截断、无回波、支架混淆、几何保留、人工修订、排除及分歧；记录所有分母和排除理由。有效检查帧不足 2 或没有姿态变化时，该类只能报证据不足，不以一个好看的帧通过。

最小可接受结果是：软件坐标链通过、可靠观测无明确矛盾、固定候选在检查轨迹上保持一致、剩余不确定已按规则记录。不能把“不是每个亮像素都贴合”单独作为失败；也不能把“包得住部分亮点”单独作为成功。连续的系统性 range/beam 偏差、错误本体身份、以 unsupported 新位姿修好检查集、多解导致框大幅变化，都不进入自动几何标签池。个别边界可由人可靠修订时可形成明确的人工修订标签，不必因此放弃整套公开数据。

## 冻结输出与停止条件

拟执行前应把上面的允许身份、坐标版本、拟合变量、物理约束、候选搜索预算、观察容差、代码/hash 和停止条件写入具体 run 预登记。本草案不替代它。

每帧保存原图身份/hash、source release、标定/mesh hash、geometry version、未裁切/裁切/修订框、可见性、截断、独立观测区间、复核类型/意见、修订原因和最终用途。几何保留与人工修订在统计和发布清单中分别可识别。正式训练及共同 paired manifest 仍需随后明确冻结；本次只完成协议设计。

源身份或坐标映射失败立即停止；无可靠约束、多解对框不稳定、拟合到支架、第二轨迹系统偏移，停止对应自动几何分支。未知帧不换成简单帧凑通过率。需要更多观测时另立有选择规则的开发抽帧计划，不访问原项目 test。
