# Camera 标注逐帧检查

打开同目录 `index.html`。该目录只存已有GT的可视化，不是新训练数据，不产生模型预测，也不修正原标签。

- `paired`：当前配对数据的全部 train/val/val_id，相机图像上的框直接来自现有 camera.json。绿色框；不抽样。
- `native`：已获准检查的40条录音中，所有具有相机标签和JPG的原始帧，包括当前37条和未完成train/val副本额外的3条。蓝色框；标签坐标按官方说明乘3，不clip或人工修正。与paired有重复帧，用于检查完整时间序列；不是未完成副本尚未落盘的最终GT。
- test 图像不打开、不导出；未扩展到未知历史角色的其他录音。旧平台/remote dense并非都在本机，不把这次导出称为覆盖所有历史平台。

浏览页可按数据版本、类别、录音、split、帧号过滤；点击图片可并排看原图与标注图，用左右键逐帧翻看。可标记正常/疑似框偏小/偏移/框不全/不确定，填写备注，并下载检查CSV。标记仅保存在当前浏览器本机存储，请导出CSV留档。浏览页需在本机浏览器打开，原图路径依赖本机D盘。

每张导出图保留原图像素大小，在上方另外加48px标题条；框坐标绘制在未缩放的图像区域。数字标注保留原GT；绘图画布以外的部分自然不可见，不等于修改或裁剪了标签。网格缩略图与浏览器自适应显示不改变完整导出图。

`manifest.json`和`image-index.csv`记录每张图的来源、现有框坐标和处理规则；`verification.json`记录导出完整性，`progress.json`为运行状态。只有状态为complete且错误为0才算全部完成。

访问记录：本轮早期对单行camera.json使用Get-Content -TotalCount 30，实际读入了包含test记录的完整混合标注文件。该访问已如实登记，不能声称本轮从未读取test标注；没有打开test图像、运行test模型评价或根据test结果修改方案。正式导出只解码明确允许的相机ID对应的GT对象，test图像保持关闭。

完成：paired 4,746张（train 2,652 / val 1,500 / val_id 594）；native 26,761张（40条录音）。共31,507张全分辨率带框图及31,507张缩略图，两套之间存在重复帧。完整性检查缺失0、失败0。请优先从paired开始检查实际训练数据中的GT，再用native查看前后连续帧。
