# 原始记录最小清单与准入要求

状态：全部待取得/未认证。这个清单不是新标定结果。

| 项目 | 最小可用交付 | 核对条件 |
|---|---|---|
| 逐录音相机设置 | 6录音→原始文件→机型、镜头模式、稳定设置表，或原文件元数据 | 可关联具体录音，注明是否全程固定；不能仅凭型号或文件分辨率 |
| 成像模型实现 | 可执行project/undistort函数或准确库API/版本、系数顺序、K/D、原始尺寸 | 能独立重投影；解释缩放/crop/去畸变/稳定处理 |
| 水下标定血缘 | 原始标定观测、板几何、介质、housing/port、录制设置和误差 | 与旧录音同配置；空气标定不得直接认证水下几何 |
| tag尺寸 | 黑色有效边界边长及测量依据，另列白边、打印纸、cube外边长 | 解释0.247m和0.30m；不是凭图像比例选择一个 |
| tag布局 | tag36h11 ID到cube面的对应、角点坐标/面变换、单位和顺序 | 20/21/141明确；真实几何测量或可核验CAD；不能仅由同一图像拟合 |
| cube稳定性 | 每录音内是否静止、录音间搬动分组 | 同ID不等于同一世界位置；跨录音比较必须先确认 |
| 同步证据 | 未裁剪文件时间轴、原匹配观测/原始音频或统一时钟日志、漂移情况 | matches.csv的索引闭合不能自己证明物理同步准确 |
| 姿态证据 | PTU/ARIS各轴定义、标定/原日志与独立控制 | 数学变换合法不能证明实测姿态准确；检查角度单位、旋转顺序、时间基准 |

有资料：先冻结来源/hash及适用录音，修复**我方副本**中的明确实现问题；固定成像模型、marker几何和每录音角色，再登记常量同步偏移的首段估计/后段验收。相机相对运动控制不需要已注册UXO mesh；固定tag与相机的相对观测可比较轨迹，已知边长才允许米制平移。

无资料：旧录音继续保留未认证状态。补拍只有在能证明旧相机、模式、housing和几何一致时，才可能约束旧成像模型；重新测量一个相似cube或新录制一条轨迹，不能恢复旧录音的实际设置/同步真值。可以另建完整记录的新采集试点，但需另行明确数据范围，不能把它的标定追认成旧发布数据真值。

现有31张控制副本可保留作相对运动/模型敏感性开发材料；自动角点、0.247/0.30假设或自由mesh调整均不能升级为认证GT。
