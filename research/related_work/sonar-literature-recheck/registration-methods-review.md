# 固定 3D 注册：raw beam ridge 约束的适用范围

2026-11-11。**方法推导与方案草案，未执行投影、优化或新标签生成。** 论文依据为 [CMHD 原文复核](CMHD-evidence.md)；下述数学解释与具体约束是我方分析，不声称来自 CMHD。适用范围为既有允许开发轨迹，原项目 test 关闭。

## 结论

已知物体尺寸、gantry 位姿和声呐成像几何时，可以用多帧 sonar 观测估计一套固定 3D 姿态并检查其一致性。**不能把每个 beam 的最亮 range bin 直接当物体长轴中心线上的对应点**：它可能来自近侧表面高光、尾翼、支架、多径或噪声，同一物理点也未必在连续帧持续最亮。仅把亮 ridge 拟合得很紧，不足以认证真实 `mesh→target`。

当前最有用的进展是：先确定软件与物理坐标映射，固定尺度及标定，再在开发拟合轨迹上使用保守的、可明确归属本体的 range–bearing 约束，保存全部等价候选，在第二轨迹上检查几何范围与框稳定性。没有必要先模拟准确声学强度，也没有必要让 mesh mask 与回波逐像素相同。

## 为什么单帧不能直接恢复完整三维姿态

为说明可辨识性，暂设 sonar 的正前方为 z、横向为 x、竖向为 y；实际实现必须以已确认的坐标约定替换，不能由此决定 beam 符号。空间点 `(x,y,z)` 的理想观测可写作 `r=√(x²+y²+z²)`、`θ=atan2(x,z)`，elevation 被二维成像积分掉。

给定 `(r,θ)`，所有允许 elevation `φ` 上的点

```text
p(φ) = r · [sin(θ) cos(φ), sin(φ), cos(θ) cos(φ)]
```

产生同样的二维 range–bearing。一个二维点不是一条可直接代入 PnP 的三维对应；它仍存在 elevation 自由度。若运动轨迹仅改变少量平移/方位、目标近似共面或远离有效视角变化，多帧也可能保留高度/姿态耦合。增加帧数不自动消除退化。

已知长度能限制长轴范围，但轴对称近似下绕长轴 roll 难以观察；只用无向中心线还存在头尾互换。中心线长度端点必须真有可确认的声学对应，否则把亮段端点当弹体端点会产生有偏姿态。腐蚀/缺损 OBJ 与名义完整尺寸的差别也不可由优化器自动判作真实尺度变化。

另有参数规范自由度：观测只约束 `T_world_target · T_target_mesh` 的乘积。如果同时自由优化两者，可以把同一个物理姿态写成无数种分解；无法独立恢复“官方 target 原点”与 `mesh→target`。因此每版只优化一种表示，并固定另一种；同时开放声呐外参、同步、target 初始位姿和 mesh 注册也会互相补偿，不能一次全部放开。

## 四种约束的强弱

| 观测 | 能提供的约束 | 不能据此认证 |
|---|---|---|
| 每 beam 最大强度 ridge | 对显著回波的 range–bearing 提示，可辅助提出候选 | UXO 身份、中心线、表面对应、完整范围 |
| 无叠图独立确认的本体回波点/弧段 | 某些回波应被物体表面投影范围容纳，能排除明显错误姿态 | 所有暗区均为背景、每个模型表面应明亮 |
| 可辨认且跨视角可跟踪的弹体端部/尾翼 | 有不确定区间的几何对应，可约束姿态和头尾 | 端点对应不明确时的唯一 3D 位姿 |
| 独立三维位置/方向测量或可信布置记录 | 固定物理坐标与注册，可用于物理验证 | 来源和精度未经核实时的“精确真值” |

## 建议的受限拟合路线

1. **软件先控制。** 固定 beam 编号、显示 flip、range 起点和 bin 宽、位姿乘法方向、单位以及所选训练图片的坐标转换；beam 符号必须由约定和已知几何控制决定，不能与目标姿态一起任意优化。
2. **观测先冻结。** 由无叠图检查记录可信本体 range–bearing 区间，支架与不明亮点不进入等式约束。最亮 ridge 只能在已冻结的本体观测区间内作候选特征；低信号帧记缺观测，不为凑拟合自动选择另一个亮峰。
3. **参数受限。** 三类保持名义尺度或有独立依据的实测尺度；每实例只拟合一套固定刚体姿态。若有可信安装平面/接触高度/长轴方向记录，可固定相应自由度；没有依据时不能假设平躺后把它当实测事实。禁止逐帧平移/旋转。不同真实摆放允许不同固定 target 位姿，但必须有独立记录或明确单列为拟合变量，不能偷偷从检查轨迹估计。
4. **使用表面支持约束。** 对每个可靠观测 `(r_i,θ_i)`，比较预测 mesh 表面在该 frame 的 range–bearing 支持集；采用单向、稳健的距离到允许带残差。区间内残差为 0；超出按 range 与 angle 的测量不确定性分别归一化后用 Huber 等稳健损失。模型没有高光的表面不计反向惩罚。不能把“双向轮廓 Chamfer 很小”当唯一目标，因为实际只部分表面发亮。
5. **防止仅容纳回波的大范围解。** 固定尺度、限制参数到有来源的物理范围；加入可信端部/安装平面约束；逐解检查未裁切包络及投影框尺寸。不能靠无限加大容许带、扩大模型或把整个图像纳入表面支持获得低损失。
6. **多个初值但固定预算。** 搜索预算和初值由粗几何而非检查帧效果预先登记。保存所有收敛/失败结果、损失分量、落在边界的参数、局部 Jacobian 奇异值及多解差异。归一化不同量纲参数后再比较 Jacobian；某个局部满秩也不能排除远处离散多解。
7. **检查轨迹不参与优化。** 使用 [框整理协议（本地产物说明）](../../ARTIFACTS.md#artifact-96411255b586)中的固定 3+3 帧分配。检查失败保留；不在同版添加 per-recording offsets 或改 beam 符号修好它。

## 对多解的处理

若 roll/头尾存在等价解但所有候选产生近似相同的几何框，可以报告“在当前候选集合内框稳定”；保留姿态不确定性，不必为框任务强行选择一个假装唯一的 3D 真值。候选范围需来自有物理依据的搜索与观测，不能只看优化器偶然返回的一个局部解。

若多解导致第二轨迹的框位置或尺寸显著不同，当前观测不足以支持自动几何标签，需增加独立约束或使用明确记录来源的人工框。助手标出的参考区间仍为 assistant 注释，不冒充专家 GT；框稳定也不等于框正确。

拟合和检查应报可靠点残差、独立边界区间违反量、同语义参考框 IoU、候选框之间的稳定性、每轨迹失败与不确定计数。当前 18 帧既有 QA 只有主观分级，没有独立完整 GT，因此现阶段不能给出已经通过的 IoU 或物理精度值。

## 追加：理想对应点敏感性诊断的独立只读审查

审查对象为 [diagnose_sonar_registration_observability.py](../../tools/diagnose_sonar_registration_observability.py)、[results.json（本地产物说明）](../../ARTIFACTS.md#artifact-1afff5e74120) 和 [README（本地产物说明）](../../ARTIFACTS.md#artifact-506d2be09fd3)。本次只读代码和已有结果，没有重跑。

代码使用每个 mesh 的 6 个轴向极值顶点，假设这 6 个顶点的跨帧身份已知。扰动是围绕固定 target 世界位置的 7 参数相似变换：3 个平移、3 个旋转和 1 个 log 尺度。它并未同时优化 `world→target` 与 `target→mesh`，因此这段局部分析没有引入前述双变换分解的规范自由度。

读审可确认解析微分与中心差分的参数化一致：平移每单位 0.01 m；旋转导数为世界轴与相对 target 原点的向量叉积，再乘 `π/180`；log 尺度导数为相对向量的 0.01 倍。range 梯度为 `p/r`，方位 `−atan2(x,z)` 的梯度也正确，随后通过固定的 sonar 旋转链传递。代码分别以 range bin 和名义位置的局部相邻 beam 角间距归一化。输出中的最大差分误差分别为 bomb `4.754e−9`、grenade `2.282e−9`、mortar `4.560e−9`；这是以 Jacobian 最大元素幅度归一化的差异，不是所有单个导数的相对误差，更不是实测姿态误差。

中心差分步长 0.01 和 0.005 对应 0.1/0.05 mm 的平移扰动、0.01/0.005° 的旋转扰动、0.0001/0.00005 的 log 尺度扰动。可见集合和 beam 归一化在名义位置冻结；导数不包含 FOV 穿越造成的可见集合变化，条件数也依赖人为归一化，不能当作经过噪声标定的协方差或精度保证。

三类第一条轨迹组合后的可见理想 Jacobian 均为 rank 7，条件数约 12.08/14.27/19.36；两条轨迹组合为 10.28/13.82/17.94。单帧出现欠秩或约 900–1000 的条件数，支持“在理想对应已知条件下，多视角能缓解当前名义几何的局部退化”。它不能证明真实高光可对应到这些顶点，也不能证明实际目标同位、注册唯一、实际误差小或任何框已准入。本文建议的定尺度受限刚体拟合是另一个 6 参数问题；该 7 参数分析只作为机制提示，不应把条件数直接搬成 6 参数方案的检验结果。

读审发现两处需要谨慎的输出表述：

- “符号翻转不改变 SVD”只有在**固定观测行集合和固定归一化**时严格成立，因为此时只是方位行乘 −1。若修改本脚本方位符号后重新寻找非均匀 beam 间距或重新筛选可见点，这两项可能改变，数值 SVD 不必完全相同。即使出现差异，也仍不能以 SVD 较好判断物理 beam 正负。
- 当前 `results.json` 保存每帧的奇异值、秩、最弱方向、差分误差和可见点数，未保存完整 `Ja/Jvis` 数组。因此 README 的“每帧矩阵都保存在 results.json”不准确，应写成“每帧 SVD 摘要”；此处为审查记录，不直接改动被审产物。
