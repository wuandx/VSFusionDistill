### 1.2 三条被反复强调、且直接改变了本次调查结论的原则

**原则一：重复层级必须等于随机化层级（伪重复陷阱）。**
UXO 是吊车连续推移录制，相邻帧高度相关。我方按**录音**留出是正确的；文献若按帧随机切分，则其指标里含大量帧级泄漏。含义：论文读数与我方读数**在统计单元上就不是同一类量**。因此本报告从不把两者放进同一张表并排（第 2.10 节），并把"换考场"单列为协议层第一原因。

**原则二：可比性破坏必须显式声明。**
任何改动（数据/预处理/指标/ckpt/基线）都会使新读数不再直接可比。含义：本文第 4 章每个方案都写一行"破坏了什么可比性 → 需要重跑什么锚点"。没有锚点重跑的数字不写进 `doc/experiments.md`。

**原则三：不要用改语义的方式制造成功。**
含义：论文增益的 98% 来自"objectness 排序后 rank 对齐的 MSE"。我方当前实现是"objectness 加权软目标 KL"，二者**目标函数不同**。复现时正确的做法是**新增**一条 rank-MSE 路径并做 A/B，而不是把现有 KL 就地改写成 MSE 后宣称"复现了 CMOLD"。

## 2. 目标重述：我们真正要复现的是什么

CMOLD 的 0.797 是**协议绑定**的读数，而且**方向也未经验证**：在 CMHD 同组的严格设定（轨迹级 6:2:2、类别均衡、640×640、50 epochs）下，CMOLD 复现得 mAP 75.3 / mAR 78.6，**低于同表无蒸馏基线 YOLOX-S-Ghost 的 77.0 / 79.9 达 1.7 个 mAP 点**（CMHD Table 6）；逐类看，CMOLD 在简单类 89.2 > 基线 87.4，在困难类 49.9 < 基线 56.5（掉 6.6 点），CMHD 的原话是"CMOLD gains slight precision on easy classes but degrades severely on hard targets"。因此"复现 0.797"不仅不是合法目标，**连"机制一定带来正增益"都不能假定**。可达成的目标分三级：

| 目标层级 | 表述 | 判定标准 | 现状 |
| --- | --- | --- | --- |
| T0 · 读法对齐 | 把"我方读数 vs 论文读数"改成同考场比较 | 主表改为"我方 val / 我方 val_id / 论文（独立列，不并列）"三列，禁止把 0.376 与 0.943 并排 | 已在 `调查/00` 2.10 与 3.8 达成 |
| T1 · 机制对齐 | 在**我方同一考场**下验证 CMOLD 的机制是否产生同类增益 | 同一 seed、同一 ckpt 家族、同一 split、同一指标代码下：仅 objectness rank-MSE 的增益方向与量级，与论文"消融主导项"结构一致；**并且必须能证伪**——若增益落点不在预期格子或方向为负，按 E3-d 停止 | 未开始 |
| T2 · 区间估计 | 给出"若按论文未披露参数（γ/λ/K/分辨率）最优取值，论文读数大致落在什么区间" | 用敏感性分析给出区间与宽度，并显式标注不可知来源 | 未开始（属 T1 的延伸） |
| T3 · 协议敏感性 | 量化"帧级随机切分"对 CMOLD 类机制的放大倍数 | 在同一权重下比较帧级对照臂 vs 录音级留出臂的增益差（E2-a + E2-c 组合），把"协议放大了机制"这一假设变成数字 | 未开始（属 T1 的延伸，也是 CMHD 负增益现象的直接检验） |

**不建议追求**：绝对值 0.797、绝对值 0.943、把 CMOLD 论文表格复制进我方台账。**也不建议把"CMOLD 一定有效"当前提**——CMHD 的实测已经给出反例。

**阈值的口径依赖（须在预登记时钉死）**：该 σ = 0.032 来自 blob 口径的三种子波动；若改用 all 口径（σ = 0.0278），阈值变为 0.056；公式复算 max(2×0.0316, 0.02) = 0.0632，文中取整为 0.063。**含义：阈值本身随口径漂移，因此每组实验必须在预登记里写明"用哪个口径的 σ"，否则"通过/不通过"可以事后调整。**【仓库】`调查/03_基线数字复核.md:192-205`（残差演算）、`:217`（阈值口径漂移条目）

## 4. 分级实验方案（Trusted Target Selection 分层）

按 `ai-research-reproduction` 的分级：**E0 文档级 → E1 推理级 → E2 评测级 → E3 训练启动 → E4 完整训练**。越往上成本越高、可信度越高。当前我方基线已在 E4（完整训练已完成并有读数），所以复现 CMOLD 的路径**不需要从 E0 重走**，而是在已有 E4 基线上做 E1/E2 级别的有界 A/B，最后才用 E3/E4 验证。

### E0 级：文档与读法对齐（零成本，本报告已达成）

| 项 | 内容 |
| --- | --- |
| 目的 | 消除"把 0.376 与 0.943 并排"这一最常见的误读 |
| 动作 | 主表三列化（我方 val / 我方 val_id / 论文单独列并注明不可比）；所有我方数字补 ckpt + seed + split 口径；标注【实测】/【仓库】/【论文】/【二手】/【推断】/【未知】 |
| 产出 | `调查/00` 2.10、3.1、3.8 |
| 可比性破坏 | 无（纯文档） |

### E1 级：推理级有界 A/B（不训练，只换评测口径/后处理）

目标：确认"读数差异"里有多少来自**评测后处理**而非模型。

| 编号 | 单一改动 | 假设 | 锚点 | 判定 |
| --- | --- | --- | --- | --- |
| E1-a | 启用 NMS 后处理的可配置阈值（NMS 0.65 / 0.45；max_per_img 100 → 300） | 论文未给 NMS（全文 "NMS" 0 命中），我方 0.65 可能过严 | 同一 ckpt 的 `val blob AP50 + AP@[.5:.95]` | 若变化 < 0.063 → 指标层彻底排除（与 3.6 预估一致） |
| E1-b | maxDets 显式设为 [1,10,100]（当前依赖 pycocotools 默认） | 排除"依赖默认值"这一不可控 | 同上 | 应与现状**逐位一致**；不一致即说明默认被环境改过 |
| E1-c | 类别无关视图与类别感知视图**同表并列**（`collapse_categories` 已实现，`per_branch_metric.py:170-187`） | 量化"类别混淆"与"类别不均衡"各自的贡献 | `AP50_class_agnostic / AP50_class_aware` 比值，逐录音 | 比值 > 1.3 的录音即类别轴失效名单（与 `doc/experiments.md:458` 交叉验证） |
| E1-d | 按"GT 框高 vs 预测框高"分层报 AP50 | 检验尺度先验是否独立于标签质量成立 | 分层 AP50 | 若低框高分层 IoU 仍系统 < 0.5 → 尺度轴独立成立 |
| E1-e | 在**开发集**内评估"按 `CLASS_LENGTH_M` 缩放 blob 框"对 IoU 的影响 | blob 框量的是回波不是目标，量化"框语义"的可修正空间 | 开发集 IoU 分布变化（**不碰 test**） | 只出可行性数字，不改 GT |

**注意**：E1 全部可在本地跑推理，不需要训练。E1-a 的 NMS 阈值属于后处理参数，走 CLI/配置覆盖，不改训练语义（符合 Patch Boundary）。

### E2 级：评测级——构造"同考场"的对照（不训练）

目标：把"论文评测集身份"这个不可知项，转化成我方内部**可测的上下界**。

| 编号 | 单一改动 | 假设 | 锚点 | 判定 |
| --- | --- | --- | --- | --- |
| E2-a | 帧级随机切分对照（**仅作对照臂，不得当主口径**） | 若帧级切分能把 AP50 拉回 0.7+，则论文读数的虚高成分可量化 | 同 seed B0 的 val_id AP50 vs 帧级对照臂 | **这一步是量化"论文可能含帧级泄漏"的上界**；对照臂结果只作敏感性区间输入，永不进主表 |
| E2-b | 类别均衡子集对照（按录音分层，每类抽等量帧） | 分离"类别不均衡"与"类别混淆" | 同 seed B0 在均衡子集上的 AP50 | 若均衡后 AP50 显著上升 → 不均衡是主因之一 |
| E2-c | "论文式考场"复刻：按 CMHD 的 UXO† 设定复刻一个子集（每类 10 条轨迹 × 均匀 100 帧 → 轨迹级 6:2:2 → 1800/600/600、640×640、50 epochs、SGD 1.25e-3） | CMHD 在**同一个设定**下复现 CMOLD 只得 75.3，且**低于同表无蒸馏基线 77.0**；在 CMHD 设定下复现我方 B0，可得到"我方 vs CMHD"与"我方 vs CMHD 无蒸馏基线"两组同口径对照 | CMHD 设定下的我方 B0 读数 + 同设定下我方 B0 蒸馏版读数 | 这是我方**唯一能与 CMHD 数字并列**的口径，也是 T1 的地基；并且能直接检验"帧级切分放大了跨模态增益"这一假设（T3） |

**E2-c 的价值**：它把"我和论文差多少"变成"我和同组后继论文差多少"，后者有可比设定（轨迹级、类别均衡、分辨率明确）。这是本调查最重要的可执行建议。

### E3 级：训练启动级——机制 A/B（单种子，有界改动）

目标：在**我方同一考场**下检验 CMOLD 机制的增益方向（论文消融显示 98% 增益来自 objectness rank 项）。

按 Patch Boundary，第一刀**不碰既有 `branch_kd.py` 的语义**，而是**新增**一条可选路径（配置开关），把两条路径做 A/B：

| 编号 | 单一改动 | 假设 | 锚点 | 判定 |
| --- | --- | --- | --- | --- |
| E3-a | objectness 项：**加权软目标 KL**（现状）→ **rank 对齐 MSE**（论文式(14)：按 objectness 降序取 top-K，第 k 位对第 k 位，α=0.5） | 论文增益 98% 来自 rank 对齐 MSE；我方现状无 rank 对齐，机制不同 | 同 seed B2 vs B2-rank：val blob AP50 + AP@[.5:.95]、val_id blob、camera head AP50、train blob AP50 | 若 E3-a 的增益量级 < 0.063 → "rank 对齐"不是关键变量，回到 CMOLD 消融的"增益来自 objectness 分数本身"的解释 |
| E3-b | 加 K 上界（论文未给；CMHD 隐含小 K 倾向） | 背景预测会引入噪声，K 太大则收益被稀释 | 同上 | 扫描 K ∈ {1, 3, 5, 10, 全部}，画增益 vs K 曲线 |
| E3-c | 分类项权重 β 单独扫描（β = 0 复现论文"Obj only"臂） | 论文 Obj-only 0.794 ≈ full 0.797 | 同上 | **复刻论文消融结构**；若我方 Obj-only ≈ full，则论文消融结论在我方成立 |
| E3-d | 增益**落点检验**：在"相机 AP50 = 1.000、声呐 AP50 ≈ 0.05–0.16"的三条 bomb 录音上单独报 AP50 | 论文机制（objectness 继承教师"目标存在性"）应优先改善"报不报框"而非"框位置" | 逐录音 AP50（`174439` / `171105` / `180722`） | **这是 T1 的核心判据**：若增益不落在 bomb 上，则机制假设不成立，应停止而非继续调参 |

**E3 的设计要点**：
- 每组只改一个变量，其余全部冻结（同 seed、同 ckpt 家族、同 split、同指标代码）；
- 全部用**新配置 + CLI 覆盖**，不动既有配置语义；
- 蒸馏路由的 λ 口径要显式定义并记录（论文 λ 未给；CMHD 侧 λ_obj=0.5 / λ_cls=0.1 是可用的参照值，但**属二手**）；
- 单种子先看方向与量级，达到阈值才进多种子。

### 4.1 明确的负面清单（不要做的事）

| 禁止 | 理由 |
| --- | --- |
| 把论文 0.797 / 0.943 与我方 val 读数放进同一张表并排 | 评测集身份不同，违反可比性原则 |
| 用帧级随机切分的结果当主口径 | 伪重复；只能作敏感性区间的上界输入 |
| 就地把 `branch_kd.py` 的 KL 改写成 MSE 后宣称"复现 CMOLD" | 违反"不改语义制造成功"；必须新增路径 + A/B |

| 把 `--split val,val_id` 的合并读数当"纯 val_id"或"纯 val" | 合并口径 n_img 1278，与两者都不同 |

## 5. 建议的执行顺序（一句话版）

1. **零成本先做**：E0（已达成）+ E1-c/E1-d（本地推理级，产出"类别混淆"与"尺度轴"两张分层表）+ E2-c 的**数据集构造**（复刻 CMHD 设定子集）+ **口径治理**（P7：落一份《口径总则》并把已有读数回填 `doc/experiments.md`，这是零成本且能立刻消除误读的一项）。
2. **再做**：E2-c 的训练（我方 B0 在 CMHD 设定下的读数）——这是唯一能与 CMHD 数字并列的口径，也是 T1 的地基；**同一设定下必须同时跑"我方 B0 不蒸馏"与"我方 B0 蒸馏"两条臂**，否则无法回答"CMHD 观察到的负增益是否在我方也发生"。
3. **然后**：E3-a（rank 对齐 MSE）单种子有界 A/B，用 E3-d 判断增益是否落在预期的 bomb 格子上；**若 E3-d 不成立，立即停止该分支并回到外环**，不进入参数扫描。
4. **最后**：E4 多种子 + 录音级区组 + 论文消融四臂复刻，出可入账的结论。

**这一步的核心判断**：我方当前最缺的不是"更好的模型"，而是**一个与文献同口径的考场**（E2-c）和**一个机制正确的蒸馏实现**（E3-a）。在 E2-c 出来之前，任何在 val 上调参得到的增益都无法回答"我方与 CMOLD 差多少"这个问题。

**另外一条不可省略的纪律**：在 E2-c 与 E2-c 的蒸馏臂出来之前，**不要把 CMOLD 的机制移植当作既定方向**。CMHD 的 Table 6 已经给出一个反例——同一套机制在轨迹级 + 类别均衡的严格设定下低于无蒸馏基线 1.7 个 mAP 点，且在困难类上掉 6.6 点。我方若跳过这一步直接移植，很可能花掉一轮完整训练预算去验证一个已被同组论文证伪的方向。
