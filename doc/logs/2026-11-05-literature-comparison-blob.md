# 与同类论文 baseline 的对比（主口径 blob，2026-11-05）

## 0. 口径前提

- 我方主口径在今日复裁为 **gt=blob**（只评有实测回波的帧），依据见
  `doc/logs/2026-11-05-projected-label-alignment.md`。
- 为使对比成立，本文另补一个**文献式考场** `val_id`：27 条训练场次的留出尾部帧
  （1,798 帧），与训练同场次、不同帧——这正是多数论文所用"随机帧切分"的实际效果。
- 三个考场不可混比：`val`（10 条从未见过的场次）< `val_id`（同场次留出帧）< `train`（自评）。
- 所有我方数字均为本机实测（5060 Ti 16G，torch 2.7.1+cu128，mmdet 3.3.0，d0 退化档）。

## 1. 我方四臂在两种考场的读数

| 臂 | 参数 | 主口径 val（未见场次，900 帧） | 文献式 val_id（同场次，1,798 帧） |
|---|---|---|---|
| E13-0 纯声呐 | 8.94 M | mAP 0.1945 / **AP50 0.3760** | mAP 0.4236 / **AP50 0.7174** |
| E13-T 教师·声呐头 | 116.58 M | mAP 0.2015 / **AP50 0.3959** | mAP 0.4666 / **AP50 0.8131** |
| E13-cam 纯光学 | 16.10 M | mAP 0.5228 / **AP50 0.8180** | mAP 0.6401 / **AP50 0.9664** |
| E13-T 教师·相机头 | 116.58 M | mAP 0.5134 / **AP50 0.8275** | mAP 0.6617 / **AP50 0.9717** |

同一份权重，只换考场：声呐 AP50 0.3760 → 0.7174（**+34.1 点**），光学 0.8180 → 0.9664（**+14.8 点**）。
这 +34.1 点就是"换场次"这一个因素的价格，也是我们与文献数字之间最大的一块差。

教师与学生之差（同一考场、同一份数据）：val 上相机 +0.95 点、声呐 +1.99 点；
val_id 上相机 +0.53 点、声呐 +9.57 点。**教师的价值集中在声呐侧，且在同场次协议下被放大。**

## 7. 对比结论

1. **在文献式考场下，我们的声呐教师 0.8131 已进入文献区间**（CMOLD 0.943、CMHD 0.770 mAP 量级），
   学生 0.7174 略低；差距来自三处可解释的因素：声呐 GT 只算实测回波（他们用投影/伪标注把每帧填满）、
   输入是 128×780 拉到 640×640（横向形变，双方同做法）、训练步数为 CMOLD 的约一半。
2. **在主口径（未见场次）下我们声呐是 0.3760**，文献没有任何一篇报这个数——因为都没做
   场次级留出。这个数字不是"比他们差一半"，是**两种考场的差**，不能并列写进同一列。
3. 我们的光学支路在文献式考场是 **0.9664（教师 0.9717）**，与 CMOLD 的相机教师 0.997 基本同档，
   反证整条管线（数据→训练→评测）没有坏，声呐的低分是声呐本身与场次泛化的问题。
4. **参数量不是瓶颈**：教师 116.58 M 只训 20,895 步，声呐 AP50 就比 8.94 M 训 62,685 步的学生高 9.57 点
   （val_id）；CMHD 用 3.00 M 的 Ghost 学生拿到 0.770 mAP，说明结构效率仍有空间。
5. **mAP 与 AP50 的落差是标签几何造成的**：我们 blob 框中位 26×22 px、边界 ±2 px 抖动，
   高 IoU 门槛天然吃亏（val_id 上 AP50 0.7174 → AP75 0.459 → mAP 0.4236）。

## 8. 写作建议

- 主表列两个口径：`val（未见场次，主）` 与 `val_id（同场次，文献可比）`，并在表注
  说明二者差 34.1 点来自场次切分；
- 与 CMOLD/CMHD 的对比放在 `val_id` 列，并注明其切分不含场次级留出；
- 不把我方 `val` 的 0.376 与文献的 0.943 直接并列，否则会被审稿人当作"方法无效"；
- 逐类表必须保留（第 5 节），它把"声呐强在迫击炮弹、相机强在航空炸弹"讲清楚，
  这是后续融合/蒸馏章节的入口。

## 9. val_id 到底"漏"了多少：与训练集的帧级对账

常见误解是"随机切帧 = 测试集在训练集里"。**并不是**：图像的 id 是互斥的。
真正的通道是**同一场次内的相邻帧**——水箱里目标与相机几乎不动，隔几十帧的两张图
在视觉上近乎重复。val_id 正是这条通道的量尺，实测：

| 项 | 数值 |
|---|---|
| train 帧数 / val_id 帧数 | 7,960 / 1,798 |
| `sonar_image_id` 交集 | **0**（图像级完全互斥，训练没见过这些帧） |
| 出现在两边的场次 | **27 / 27**（全部场次都同时有训练帧与留出帧） |
| 到同场次最近训练帧的间隔（帧） | 最小 9 / 中位 **33** / 最大 73 |
| 间隔 ≤ 30 帧的比例 | 38.4% |

按采集帧率约 2.97 fps 折算，中位间隔 33 帧 ≈ **11 秒**。也就是说：考卷上的每道题都是
新题（图像级不重复），但都出自**同一个考场、同一批布景**，而隔壁就是练习题。

文献的随机切帧比这更松（相邻帧也可能一边训练一边测试），所以 val_id 是我们能给出的、
**偏保守**的文献式近似。
