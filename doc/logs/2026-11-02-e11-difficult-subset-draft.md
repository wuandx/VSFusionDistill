状态：草案，供用户与指导人采用或修改。采用后并入 `doc/experiments.md` E11 节"预登记修订"B 类第 3 条，在任何 val 评测命令执行前生效。第 3 节阈值栏暂空，按第 5 节顺序在 inventory 落盘后、split 落盘前冻结填入。依据：复盘 `doc/f2-rethink-2026-11-01.md` §9.2 b（路线 B 下声呐侧看高 IoU 口径与困难子集；困难子集须在 val 开封前只用录音清点属性写定，不能用模型输出挑）。

## 1 冻结规则（先于一切定义）

1. 子集判定只允许用 inventory 与 projection report 的字段（模型无关的清点与经典标定量），不允许用任何模型输出，不允许用任何录音的 split 归属。
2. 连续轴的分位阈值在"通过标定质量过滤（blob 帧 ≥ 30、行残差 p50 ≤ 10 px、方位残差 rms ≤ 3°）的全部录音"上计算，计算时点早于 split 落盘（此刻不知道任何录音的 val/test 归属），数字写死在本文件后不因 val 构成回改。
3. 子集归属按录音级二值判定，不做连续加权；val 上子集不足 3 条录音时该子集只记录不判定（与台账 §6 规则 2 的地板规则同构）。
4. E11 中子集读数只报告不设门；E12 起若要在子集上主张效应，效应阈值另在 E12 预登记中定义，尺子用 E11 判据 4 实测的 σ。

## 2 清点字段（含 2026-11-02 新增）

清点工具今晚补三个字段（只增读数，不动任何已有门；测试在 `tests/test_uxo_inventory.py`）：

| 字段 | 定义 | 轴 |
|---|---|---|
| `dist_median_m` | 逐帧 |声呐头位置 − 标定目标位置 P| 的中位数（米）；同报 min/max | 距离 |
| `blob_contrast_median` | 检出帧上 blob 峰值/帧背景中位比的中位数 | 回波对比度 |
| `gt_aspect_median` | 相机 GT 框长宽比的中位数 | 目标姿态（相机投影代理） |
| `blob_ratio`（已有） | 经典 blob 检出帧占比 | 回波可见度（对照刻度） |
| `geometry`（已有） | arc / line / aim | 几何 |
| `moving_target`（已有） | 录音内单调漂移超画面 10% | 目标运动（已有单列维度） |

## 4 报告口径

- 每个子集在 val 上报：类感知 blob AP50 与 mAP@[.5:.95]，3 种子均值与 σ（同 E11 判据 4 的尺子），与全集并排；子集的录音数与帧数随表给出。
- 全部子集归属由 inventory + split manifest 机械复算，脚本与输出随 E11 产物入账。

## 5 生效顺序（时间线）

1. 标定收尾（进行中）→ inventory 落盘（含第 2 节新字段）。
2. 在过滤后录音清单上计算 p33/p67 与 DS-faint 回退判定，写死第 3 节阈值栏。此刻早于 split 落盘。
3. split 落盘，manifest sha256 入台账。
4. 用户与指导人采用或修改本草案；修改涉及阈值的，须在 val 开封前重新冻结并注明原因。
5. E11-1 首次 val 评测即 val 开封；此后子集定义只读不写。

顺序颠倒（尤其第 2 步晚于第 3 步）则本草案作废重议。

## 6 已知局限

- 距离轴是录音级中位数：声呐头沿弧线扫掠使录音内距离在 min/max 间变化，中位数只是录音的代表值。
- 回波对比度与标定门控共用同一个经典 blob 检测器，与训练模型无关，但不是完全独立的信息源。
- val 约 11 条录音，连续轴子集约 3–5 条，DS-aim 可能不足 3 条而落入"只记录不判定"；这是平台规模的现实约束，如实报告。
