## 3. A 层：推理级，不训练（小时级，5090）

| # | 动作 | 对齐哪一格 | 说明 |
|---|---|---|---|
| A1 | E2-a 帧级随机切分对照臂：同一份 E13-0 ckpt，split 按帧随机重切（同比例）重评 | 评测集身份（论文唯一不可知大项） | "论文口径下我方读数"的唯一实测途径；预期 ≥ val_id 0.7174 |
| A2 | E1-c 类别混淆分层表（`collapse_categories` 已实现） | 解释 val_id 残差 | 类无关 0.3805 vs 类感知 0.2696，差 0.11 = "认错类"独立存在 |
| A3 | E1-d 按 GT 框高分层的 AP50 与 IoU | 解释 val_id 残差 | 第一步必须先在 dense 平台重测"预测框高 vs GT 框高"——历史值 28 vs 12 px 出自 E07 的**单条录音 100927、旧 sample 平台**（`doc/experiments.md:261`），E08 的"尺度轴已修"又被后续勘误撤回（`:16`、`:281`），该数不能当现平台事实引用 |
| A4 | E1-e blob 框按 `CLASS_LENGTH_M` 缩放的 IoU 可行性（开发集，不碰 test） | GT 语义前置评估 | 先算"答案改成目标真实尺寸能救回多少 IoU"，只出可行性数字 |

四件事合起来：A1 定"和论文比该用哪个数"；A2+A3+A4 把 val_id 残差 22.6 点拆成类别 / 尺度 / 框语义三块。**它们决定 C 层训练预算往哪花。**

## 6. 补不了的：论文侧永久未知，只记偏离

γ（伪标阈值）、λ、K 上界、**输入分辨率**（全文零命中）、划分方式与比例、种子、NMS 阈值、增广细节、每类样本量、N_L、|D_P|、教师是否 COCO 预训练。完整 30 项见 `docs/investigation/01_CMOLD论文规格.md` §7。处理方式：**记录偏离，不猜**。

## 7. 结构性事实：对齐的两条路

论文的声呐 GT 是伪标（初检器 → γ 筛选 → 扩量 → 质检），其 baseline 0.661 就是在伪标数据上训的。我方 GT 是投影 + blob，属 CMHD 一族（CMHD 原文同为几何投影 + 人工目检）。

| 路 | 内容 | 可行性 |
|---|---|---|
| 字面复刻 CMOLD | 复刻伪标流程 | 受阻：γ/N_L/|D_P| 全未知；同组 CMHD 复现它只得 75.3、低于无蒸馏基线 1.7 点 |
| 对齐 CMHD 严格协议 | E2-c（B2） | 参数全披露、有同口径参照数，**唯一能落地的对齐目标** |

我方 GT 生成方式已在第二条路上；要补的是**质量**（B1），不是机制。

## 8. 同性质考场（val_id）下的差距账

| 口径 | 论文 baseline | 我方 E13-0 | 差 | 主要归属 |
|---|---|---|---|---|
| AP50 | 0.943 | 0.7174 | 22.6 点 | GT 语义 + 类别失衡（bomb 0.0248）+ 增广 + 步数 53% |
| AP75 | 0.764 | 0.459 | 30.5 点 | 框质量主导 |
| mAP | 0.661 | 0.4236 | 23.7 点 | 合成 |

各项预期移动（定性）：

| 做的事 | 预期缩小 |
|---|---|
| A1 | 不缩小差距；把"论文口径下我方读数"变成实测 |
| B1 | AP75/mAP 的大头；AP50 中等 |
| B2 | 不缩小与 CMOLD 的差；给出与 CMHD 的同口径差 |
| C2 | 小（train 已记满） |
| C3 | 不缩小 baseline 差；只回答"论文增益在我方考场是否为正"（当前证据倾向为负） |
| C1 | 对 baseline 差距零贡献——差距全在学生侧考卷与答案上 |

## 9. 建议顺序（当前阶段：baseline，未到蒸馏）

1. **A1**（帧级对照臂）：最便宜、信息量最大。
2. **A2/A3/A4**（三张分层表）：一晚上出齐。
3. **B1**（GT 修正）：等 A4 可行性数字再决定。
4. **B2**（小考场复刻）：蒸馏前的前置；CMHD 负增益反例未排除前 C3 不发车。
5. **C 层最后**：教师选型随 E12 预登记走，rank-MSE A/B 在小考场里做。

停止条件沿用既有约定：增益 < max(2σ, 0.02) = 0.063 视为无证据；预登记须写明 σ 来自哪个口径（blob σ=0.032 → 0.063；all σ=0.0278 → 0.056）。
