# 声呐 val 失败场次诊断（2026-11-05）

问题：dense 平台把训练帧从 1,650 提到 7,960 后，声呐 val 仍固定有 4 条场次接近 0 分。
数据量已排除，本文件查明它们到底是什么问题。工具：`tools/session_diag.py`（只读，不需要 GPU）。

## 2. 三个结论

### 结论一：不是"看不见"，是"不报"

四条失败场次的对比度是 **+2.79 / +3.50 / +5.18 / +4.41**，与成功场次（+1.83 到 +4.94）完全重叠，
其中 124915 的 +5.18 是全表最显眼的一条，却只有 0.029。

真正的现象是**几乎不出框**：171105 有 33 个回波帧却只报了 10 个框，174439 有 20 个帧只报 1 个，
180722 有 22 个帧报 8 个。objectness 分支在这些外观上根本没被激活。

### 结论二：这是"类别 × 模态"问题，不是"场次"问题

按类别拆开，失败高度集中在 **bomb**：

| 类别 | val 场次 | 声呐 AP50 | 相机 AP50 |
|---|---|---|---|
| bomb | 3 条 | **0.14 / 0.00 / 0.16（全灭）** | 1.000 / 1.000 / 1.000（全对） |
| mortar | 4 条 | 0.81 / 0.70 / 0.36 / 0.91 | 0.44 / 0.44 / 0.07 / 1.00 |
| grenade | 3 条 | 0.65 / 0.81 / **0.03** | 1.00 / 1.00 / 0.93 |

bomb 在声呐上**三条全灭**，在相机上**三条全对**。这不是随机场次波动，是一整个类别没学会。
训练侧 bomb 只有 7 条场次（全平台 13 条，7/3/3 切分），是最小的类。

### 结论三：两条"异常"要分开解释

- **124915（grenade）**：回波最亮（+5.18）、框 23×23、68 帧有回波，声呐 0.029 而相机 0.926。
  单场异常，尚未定位（可能与目标朝向或舱壁多次反射有关）。
- **105856（mortar）**：相机只有 0.072，**连相机都认不出**。这条是相机与声呐的**共同盲区**，
  与 124915 性质不同，蒸馏也救不了。

## 3. 对论文与 P2 的意义

失败恰好落在 **"相机全对、声呐全错"** 的格子里（bomb：相机 1.000 / 声呐 ~0.05）。
这正是跨模态蒸馏唯一能发力的位置：教师从光学图像里知道炸弹在哪、有多大，学生只有声呐图。

两个预期管理：

1. 如果 P2 成立，**增益最应该出现在 bomb 上**。届时看逐类表就能验证，不必只看总 AP50。
2. bomb 只有 7 条训练场次，蒸馏也可能救不动。若 P2 只在 mortar/grenade 上有效，结论必须按类写，
   不能笼统说"跨模态蒸馏有效"。
