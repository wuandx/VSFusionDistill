## 3. 遇到的问题（P1–P6，按影响排序）

### P1 · 口径分裂：同一批数字被按三套口径叙述

**现象**：2026-11-05 当天成文的文档对"主口径是 blob 还是 all"说法互相矛盾——`doc/logs/2026-11-05-gt-metric-decision.md:3` 定 blob；`…-consolidated-teacher-student-table.md:4` 写 all 为主；`…-literature-comparison-blob.md:5` 写 blob；组会材料（仓库外，`进度/2026-11-05_组会任务对照与现状.md:94-95`）写"与文献同口径的是 all"。
**量级**：同臂 all 比 blob 低 0.07–0.13（相对 26%–37%），足以让同一个结论翻转。
**影响**：对外数字无法自洽，任何 A/B 的增量都会被口径噪声吃掉。
**处置**：主口径已复裁为 blob（11-05），其余文档需逐处改引；对外只报一套主口径 + 一行诊断列。**此项待办，本次未改旧文档。**

### P2 · 与论文不可比：考场不同

**现象**：CMOLD 全文 15 页无 "test set"，唯一规模数字是 "nearly 4700 image pairs … used for training and validation"（`:575`），划分方式、单位、种子均未给。
**实测**：同一份 E13-0 权重，只把评测集从"同录音留出帧"（val-ID）换成"未见录音"（val），AP50 从 0.7174 掉到 0.3760，**差 34.1 点**。
**量级估算**：把三种起点（0.2696 / 0.2584 / 0.1769）各加回这 34.1 点，残差 0.3320 / 0.3432 / 0.4247，即"真实能力差"落在 **1.54× ~ 1.82×**；"换考场"一项占 AP50 总差（0.6734）的 **50.7%**。
**影响**：把 0.2696 与 0.943 并列会得出"方法无效"的错误结论——这是最容易被审稿人抓住的一处。
**处置**：对外主表分两列（val 主 / val-ID 文献式），论文数字单独成表并注明不可比；不追 0.797，追"同考场相对增益"。

### P3 · 声呐 GT 语义：框量的是回波，不是目标

**现象**：原始数据集只提供相机 GT，声呐框由自研投影生成。11,558 个声呐框中 **46.4% 是几何投影框**；投影框到亮回波中心的中位偏移 **25.4 px**（框宽 40 px），**63.4% 超过半框宽**；blob 框（实测回波连通域）中位偏移仅 5.6 px。
**更深一层**：blob 框圈的是"99.5 分位亮度连通域"，即回波斑块。实测同类目标的回波物理高度跨录音离散约 **2.3 倍**（bomb 44.7–101.4 mm、grenade 35.8–77.5 mm、mortar 35.8–80.5 mm）。论文与 CMHD 的声呐框是目标框。
**影响**：AP@[0.5:0.95] 对框语义的惩罚远重于对"检出"的惩罚；这也是 mAP 与 AP50 落差大的主因之一（val-ID：AP50 0.7174 → AP75 0.459 → mAP 0.4236）。
**处置**：训练只用 blob（已是现状）；主口径 blob 已规避大半；"回波 ≠ 目标"的残余无法靠换口径消除，只能靠按类别长度缩放 blob 框做开发集可行性评估（未做）。

### P4 · 类别失衡与逐类地板

**现象**：val blob 帧中 mortar 322 / grenade 131 / bomb 75（mortar 占 61%）；训练侧 bomb 只有 7 条录音。逐类 AP50：mortar 0.4893、grenade 0.2947、**bomb 0.0248**；而类无关 AP50 = 0.3805。
**影响**：类感知 AP 逐类平均，bomb 一类几乎归零即拖掉三分之一；类无关与类感知差 0.111 说明**类别混淆**独立存在（不只是分布不均）。val 10 条录音里 2 条整条 AP50 = 0.0000（174439：只出 2 个预测；124915：出 31 个预测但全错）。
**处置**：主表必须带逐类列；bomb 按"只记录不判定"处理（n=3 录音）；类无关口径作为诊断列同报。

### P5 · 平台/可复现性

**现象一**：dense 平台的 7,960 帧由**仓库外**的 converter 补丁生成（`--max-frames-train`，仓库 `aodet/datasets/converters/uxo_to_paired.py` 的 CLI 只有 `--max-frames`），且 GT 依赖外部 `projection_calib.json` 缓存。仓库 HEAD 复现不出该平台。
**现象二**：`tools/train.py:53` `deterministic=False`，单种子读数不可严格复现。
**影响**：dense 平台的任何读数第三方无法复现；跨机对比只能靠"同配置换机差 ≤ σ"这类弱判据。
**处置**：把补丁以可审计 diff 纳入仓库（或记录哈希）；至少在台账注明"该平台不可由 HEAD 重建"。

### P6 · 台账与产物可追溯性

**现象**：E11-1 已按 24h 规则入账；但 **Bcam×3、B2 声呐头、E13 三臂、五份 11-04/05 诊断 log 均未入账**（台账 §3 的 E13 节仍是预登记文本）。本机 `results/` 只有声呐/相机 B0 的 `ap_summary`，其余读数散在 `doc/logs/`。
**影响**：同一批数字有多个出处，更新一处不会同步另一处——这正是 P1 能长期存活的土壤。
**处置**：把 E13 三臂与诊断读数按五段格式补进台账 E13 节；本次未写（避免与导师正在维护的台账冲突），列为 §5 待裁定。

## 4. 与 CMOLD / CMHD 的可比性边界（三档）

**可比**：检测器框架与容量档位（YOLOX-S）、优化器与学习率（SGD 1.25e-3 → 6.25e-5 / mom 0.9 / wd 5e-4 / batch 8，与 TABLE 2 完全一致）、AP/AR 指标定义与 maxDets、每帧恰 1 目标 / 3 类 / 同源数据。

**部分可比（需并列并注明）**：声呐 AP50 可作量级参照，mAP 不可；相机支路（我方 0.8101/0.8471 vs 论文教师 0.997，差 15–19 点——这一路没有伪标签也没有投影几何，差距不可能由声呐 GT 解释，只能归到考场与训练配置）；蒸馏增益方向可对照"objectness 主导"这一结构，不可对照绝对值。

**不可比（禁止并列）**：我方 val 读数 vs 论文读数；声呐 GT 质量与语义（伪标 vs 回波连通域框）；划分单位（录音级 vs 论文未述）；增广强度（我方可见 vs 论文一句带过）。

**一条需要写进正文的反例**：CMHD 在它自己的严格设定下复现 CMOLD 得 mAP 75.3 / mAR 78.6，**低于同表无蒸馏基线 77.0 / 79.9 达 1.7 个 mAP 点**（困难类 49.9 vs 56.5）。即"CMOLD 机制一定带来正增益"这个前提**尚未成立**。我方若直接移植，可能花一轮训练预算去验证一个已被同组论文否定的方向。
