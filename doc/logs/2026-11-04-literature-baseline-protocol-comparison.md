# 2026-11-04 声呐目标检测公开 baseline 与本文 B0 的口径对照

起因：用户先问"有没有其他声呐目标检测论文的 baseline 和我的对比一下"，随后追问"目前比较好的、用到过这个数据集的论文，他们是怎么跑基准的，我们参考采纳就行"。本文分三层回答：其一，Dahn UXO 数据集（我们用的这一份）上真正跑过检测基准的论文只有两篇，逐条列出它们的协议；其二，其它声呐数据集上的公开 baseline 与我们 B0 的三级读数并列，说明"0.27 对 0.94"的差距来自协议而非模型强度；其三，按性价比给出可直接采纳的清单。检索日 2026-11-04；数字来源见文末，标 † 者为仅据摘要/搜索片段核对、未读全文表格。

## 二、CMHD 的基准协议（最值得采纳的一份）

数据与划分（§3.1）：原始集 95 条轨迹、74,437 声呐帧，其中 48,462 帧有相机配对、37,278 帧有相机框。作者按"每类随机挑 **10 条完整采集轨迹**（须带 RGB 框）→ 每条轨迹**均匀抽 100 帧**"采样，**按轨迹 6:2:2 切分**，得到 **1,800 训练 / 600 验证 / 600 测试**，各切分**类别均衡**（每类 200 测试样本）。声呐 GT 由目标初始位姿 + 云台运动轨迹 + 声呐外参 + ARIS 极坐标成像几何**逐帧投影**生成，再做人工目检剔除明显错位——与我们 `project_uxo_sonar.py` 同路线，差别是他们做了人工剔除、我们只做 20px 门限筛选。

训练配置（§3.2）：输入 **640×640**；**50 epochs**；batch 8；SGD；初始 lr **1.25e-3** → 最终 lr **6.25e-5**；momentum **0.9**；weight decay **5e-4**。环境 Python 3.8.20 / PyTorch 2.4.1 / CUDA 12.2 / RTX 4090 / i9-13900K。

指标（§4.1）：主指标 **AP@[0.50:0.95]**，另报 **AR maxDets=1**（理由：该子集每帧恰一个目标）。不报 AP50。

对比臂（Table 6，全部在同一切分、同一 640 输入、同样 50 epoch、同一优化器下重训）：

| 臂 | 说明 | mAP@[.5:.95] |
|---|---|---|
| YOLOX-Nano | 轻量基线，无蒸馏 | 0.673 |
| YOLOX-S-Ghost | 本文学生结构，无蒸馏（纯架构对照） | 0.770 |
| KD-YOLOX-ViT（Aubard 等 2024） | **同模态**（声呐）蒸馏，教师 YOLOX-M-ViT → 学生 YOLOX-S-ViT | 0.716 |
| CMOLD（作者复现） | 按 CMOLD 同构师生设计，师生均为 YOLOX-S-Ghost | 0.753 |
| **CMHD** | RGB YOLOX-M 教师 → 声呐学生 | **0.796**（mAR 0.826） |

附加：困难子集（从三类中人工挑 100 张——33/33/34，强斑点噪声、弱边界、低对比）上 CMHD mAP 降到 **0.461**，五臂全部明显退化。

消融的摆放（可整段照搬的模板）：学生结构（Nano vs S-Ghost）、**教师容量（YOLOX-S / M / L）**、蒸馏来源（自蒸馏 / 同模态强教师 / 跨模态）、蒸馏分支（cls / obj / 两者）、权重敏感性、复杂度与 FPS、失败案例（类间混淆 + 定位偏移）。

蒸馏细节：教师置信度**门控** `M = 1[p_obj^T · max_c p_cls^T(c) > τ]`，τ = **0.5**（候选 0.3/0.5/0.7 择中）；权重 **λ_obj = 0.5、λ_cls = 0.1**（非对称）；ε = 1e-6；框回归损失权重 5；**不做框蒸馏**（几何不一致）；教师先独立训好再冻结。

## 三、CMOLD 的基准协议

数据与划分（§4.A）：~4,700 对用于"训练与验证"，**正文未述录音级切分**；声呐 GT 由"小规模人工标注子集 → 初检器按置信度阈值 γ 伪标注其余 → 合并"得到（自证循环）。

训练配置（Table 2）：**200 epochs**；batch 8；SGD；初始 lr **1.25e-3** → 最终 lr **6.25e-5**；momentum **0.9**；weight decay **5e-4**。输入分辨率未在表中给出，正文只说明师生共享同一输入分辨率。环境 Python 3.8.20 / PyTorch 2.4.1 / CUDA 12.9 / **NVIDIA L4**。

指标：AP@0.50、AP@0.75、AP@[0.50:0.95]，AR@1 / AR@10 / AR@100。

对比臂（Table 5，四臂）：

| 臂 | 说明 | mAP@[.5:.95] | AP@.5 | AP@.75 |
|---|---|---|---|---|
| YOLOX-Sonar Only No KD | 纯声呐 YOLOX-S | 0.661 | 0.943 | 0.764 |
| YOLOX KD（同模态） | 教师 YOLOX-M（25.3 M 参数 / 73.8 GFLOPs）→ 学生 YOLOX-S（9.0 M / 26.8 GFLOPs），均只训声呐 | 0.671 | 0.948 | 0.766 |
| YOLOX ViT KD | 同上加 ViT 层（M-ViT → S-ViT） | 0.688 | 0.949 | 0.771 |
| **YOLOX-CMOLD** | 相机教师 → 声呐学生 | **0.797** | 0.949 | 0.828 |

附：相机教师（同分布）mAP **0.958** / AP50 **0.997**；逐类学生 AP——100lbs_aircraft_bomb 73.45%、incendiary_grenade 77.41%、mortar_shell 47.29%；教师同序 97.56 / 97.49 / 91.86。

蒸馏细节：α = β = 0.5、τ = 2；按 objectness 排序取 **top-K** 对齐；objectness 用 MSE、类别用 KL×τ²；**不蒸框回归**；总损失 `L = L_det + λ·L_CMOLD`。

## 四、两篇的对比臂逐条对应

用户问的"4 个 / 3 个"是两篇表里**除自己以外**的方法数：

| | CMHD（5 行 = 4 对手 + 自己） | CMOLD（4 行 = 3 对手 + 自己） |
|---|---|---|
| 纯声呐无蒸馏基线 | YOLOX-Nano 0.673 | YOLOX-Sonar Only 0.661 |
| 本文学生结构、无蒸馏 | YOLOX-S-Ghost 0.770 | （以 YOLOX-S 作基线，见上一行） |
| 同模态蒸馏（Aubard YOLOX-ViT KD） | 0.716 | 0.671（纯 KD）/ 0.688（ViT KD） |
| 对方方法复现 | CMOLD 0.753 | 无 |
| 本方法 | CMHD 0.796 | CMOLD 0.797 |

要点：两篇**独立地把 Aubard 的同模态蒸馏复现到同一份数据上**，分别只拿到 0.671–0.716，而跨模态都在 0.79 左右——这是"跨模态才有大增益"的最干净证据，也是我们写论文时最该照抄的负对照结构。

## 八、解读

其一，**已核对的九篇论文无一做录音级留出**。UATD 系列用官方帧级随机切分；侧扫与前视的改进论文同样只报帧级划分；CMHD 做轨迹级 6:2:2 但各类切分共享同一采集池、且类别均衡；CMOLD 未述切分。声呐数据是连续采集的帧序列，随机切分意味着测试帧与训练帧时间上相邻，因此 0.80–0.94 是该口径的常态水平，不能读作"比本文 B0 强 3 倍"。

其二，**CMHD 给出了跌幅参照**：标准集 0.796 → 困难子集 0.461（−33.5 点）。本文 val 相对 val-ID 掉 33 点（0.589 → 0.258）与之同量级，属同一物理机制，不是训练或管线故障。

其三，**CMOLD 的 0.943 与本文 0.270 不可并列**：伪标注 GT（自证循环）+ 无录音级切分 + 同分布验证；其相机教师 0.997 亦为同分布读数。

其四，**本文三级读数把文献两端都量了出来**：见过的录音 + 见过的帧 1.0000；见过的录音 + 没见过的帧 0.589；没见过的录音 0.258。文献口径落在第二档附近，因此"若按文献协议评测本模型会得多少"**没有实测数**——最接近的代理是 val-ID 的 0.589，不能宣称"换协议也能 0.94"。

其五，**两侧证据支持协议主导论**：旧 sample 平台（3 条录音、无 val）下 E05 train AP50 0.80 对 test 0.0001、E07 train 0.904 对 test 0.005，同一套代码在"换录音"口径下归零；本平台把录音级划分与几何轴解耦后 val 从地板升到 0.258±0.032。

其六，**教师容量的证据与我们默认选择相反**：CMHD 的教师消融显示 RGB **YOLOX-M 综合最优**，YOLOX-L 与 S 虽在个别类上突出但在难类（迫击炮弹）上波动明显，因此"中等容量教师更利于蒸馏"。我们 e12 正在训的是 **YOLOX-L**，应把 M 作为平行一臂而非默认最优。

## 九、采纳清单

P0（零成本，只改报告口径）
1. 主指标改为 **mAP@[0.50:0.95]**（本文 B0 = 0.110），AP50 降为辅助列——两篇都用 mAP 作头条。
2. 补报 **AR maxDets=1**：本文 val/test 全为单目标帧（528 blob GT 对应 528 帧），与 CMHD 的设定完全对口。重跑一次评测即可（分钟级）。

P1（低成本、高价值，各 1 臂 GPU）
3. **教师容量消融 S / M / L**：CMHD 的结论指向 M；我们已排 L，建议并排一臂 M，用 val 相机 AP 定胜负（约 12 h/臂）。
4. **epoch 敏感性 50 / 100 / 200**：CMHD 只训 50、CMOLD 训 200、我们 304 且已知过拟合；这三档的信息量大于"再加 100 epoch"。

P2（中成本，论文中需要）
5. **把 CMOLD 按同预算复现到我们的划分上**：这是唯一能构成公平对比的对手（CMHD 也是这么做的）。CMOLD 未公开代码，需自行实现 top-K objectness 对齐 + 类别 KL（τ=2）+ objectness MSE；仓库 `branch_kd` 骨架已有 cls/obj 概率，改造量可控。
6. **采纳 CMHD 的两个技巧**：教师置信度门控（τ=0.5）+ 非对称权重（λ_obj=0.5、λ_cls=0.1），正好对应组会说的"筛选"那条 trick，可作 E12 的对照臂。

P3（要人力）
7. 困难子集（约 100 帧人工标注）：CMHD 用它证明鲁棒性掉到 46.1。我们已有 4 条整条失效的录音，天然是候选池，但标注需人工。

不采纳：类别均衡重切分（会作废现有 B0/Bcam/B2 全部 baseline）。

## 十、结论与写作建议

结论：本文 B0 的 0.258 ± 0.032（val blob AP50）/ 0.110（mAP）不是"低于文献"的异常值，而是**同一模型在录音级留出口径下的首个读数**；文献高分的三个来源（同分布切分、类别均衡采样、自制或伪标声呐标签）我们一条未用。协议严格性是差异，不是模型劣势。

论文中该表按三行并列，勿与文献并排：

```
                        mAP@[.5:.95]   AP@0.50   AR@1   协议
B0  train 自评            0.985        1.0000    —      见过的录音（上界参考）
B0  val-ID                0.315        0.589     —      同录音留出帧（≈文献口径）
B0  val（未见录音）        0.110        0.258     —      录音级留出（本文口径）
```

脚注："文献 [UATD, CCW-YOLOv5, BES-YOLO, CMHD, CMOLD] 均采用帧级随机切分或轨迹级共享采集池划分，其测试帧与训练帧来自同一采集序列；本文额外报告录音级留出，用于衡量跨场景泛化。数字口径为 blob GT、COCO 式 AP。"

若审稿人要求"与文献同口径的可比数字"，最省的补法是新增一条**帧级随机切分**评测臂（训练不动、只重切测试集并重算 AP），按台账"单种子协议"登记为独立实验，不与 E11/E12 混排；该数预计落在 0.589 与 1.0 之间，可作附录。
