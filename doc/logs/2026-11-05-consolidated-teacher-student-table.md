## 三条读表须知

1. **列不可跨组直接比 epoch**：旧平台 304 epoch = 62,928 iter，dense 63 epoch = 62,685 iter，**训练步数相同**；
   epoch 数不同只是每 epoch 的 iter 数从 207 变成 995。所以 A 组与 B 组是"同预算、不同数据密度"的对照。
2. **C 组不是同预算对照**：旧教师只训了 21,000 iter（与 B 组教师同为 2 万步级），但训练数据只有 3 个场次。
   它和 B 组教师的差别同时包含"数据量"和"场次数"两个因素，只能说"旧教师在我们考场上是这个水平"。
3. **blob 列不可与 all 列混用**：blob 把 372 帧弱回波帧整帧排除，数值天然偏高（同臂高 0.07–0.13）。
